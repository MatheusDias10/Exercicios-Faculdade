Aula sobre Position (Posicionamento em CSS)

Position pode ser static, relative, absolute, fixed ou sticky

1. Propiedade position

É uma propiedade de posicionamento que trabalha com top, right, bottom, e left

Possíveis valores:

  • static: valor padrão, segue o fluxo normal do documento
  • relative:posicionado em relação à sua posição original
  • absolute: posicionado em relação ao elemento pai
  • fixed: posicionado em relaçãpo à janela do navegador (viewport)
  • sticky: híbrido entre o relative e o fixed

2. Position static

O elemento html segue o fluxo normal da página. Esse é o nosso padrão, top , right, bottom, left não tem efeito neste valor

                
                    #caixa {
                        position: static;
                        top: 30px;
                        left: 30px
                    }

3. Postion relative

O elemento continua ocupando seu espaço original no fluxo do documento, mas será deslocado conforme indicado no top, left, bottom e /ou right

                
                    #demo-relative {
                        width: calc(100% - 40px);
                        height: 50px;
                        position: relative;
                        top: 20px;
                        left: 40px;
                        background-color: #a13342;
                    }

4. Postion code absolute

O elemento é removido do fluxo normal do documento e passa a se posicionar em relaçãoao elemento pai

O elemento pai deve ser Postion Relative

                
                    #container {
                        position: relative;
                        height: 200px;
                        border: 1px dashed grey;
                        widht: 100%;
                    }


                    #demo-absolute {
                        height: 50px;
                        width: calc(100% - 40px);
                        top: 10px;
                        left: 10px;
                        position: absolute;
                        background-color: #a13342;
                    }

5. Position fixed

O elemento sai do fluxo normal do documento e será posicionado em relação à janela

                
                    #demo-fixed {
                        position: fixed;
                        bottom: calc(100% - 25px);
                        right: calc(100% - 50px);
                        height: 100px;
                        widht: 100px
                        border-radius: 25px
                        background-color: #a13342;
                    }
